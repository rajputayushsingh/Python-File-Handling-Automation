# 📁 Python File Handling Automation

A Python-based file automation project that automatically organizes files into different folders based on their file extensions.

This project helps keep folders clean and organized by categorizing files such as images, documents, videos, audio files, ZIP files, and Python files.

---

## 🚀 Features

- 📂 Automatically organizes files
- 🖼️ Supports image files
- 📄 Supports documents
- 🎥 Supports video files
- 🎵 Supports audio files
- 📦 Supports ZIP/RAR/7Z files
- 🐍 Supports Python files
- 📁 Creates category folders automatically
- 🌐 Flask web interface
- ⚡ Simple and beginner-friendly

---

## 🛠️ Technologies Used

- Python
- Flask
- OS Module
- Shutil Module
- HTML
- CSS
